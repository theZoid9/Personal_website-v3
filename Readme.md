# Zaid Akhalwaya — Portfolio

A light, side-scrolling React portfolio built with Vite. The Applications panel uses arrow controls to switch between selected work and a Place Marker mobile app concept, with a separate All Projects page.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`, then preview it with `npm run preview`.

Project previews, the portrait, CV and display font live in `public/` so Vite includes them in production builds.
